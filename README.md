# Maze Game – Unity

Proyecto académico desarrollado en *Unity 6* como práctica de programación de videojuegos.

El objetivo del proyecto es implementar un *juego tipo laberinto*, donde una esfera controlada por el jugador debe desplazarse a través de un entorno con colisiones físicas.

------------------

# Tecnologías utilizadas

* Unity 6 LTS
* C#
* Unity Physics (Rigidbody + Colliders)
* Git + GitHub para control de versiones

------------------

# Funcionalidades actuales

* Movimiento de una esfera utilizando *Rigidbody physics*
* Control del jugador mediante *script BallController*
* Sistema de *colisiones con muros*
* Escena base con:

  * Cámara
  * Luz direccional
  * Suelo
  * Objeto esfera (jugador)
  * Muro de prueba
